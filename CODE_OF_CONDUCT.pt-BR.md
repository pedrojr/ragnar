# Código de Conduta

[English](CODE_OF_CONDUCT.md)

Este projeto adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso, acolha quem está chegando, aceite críticas construtivas e foque no que é melhor para a comunidade. Assédio, ataques pessoais e discriminação não são tolerados em nenhum espaço do projeto.

Para relatar um problema, fale com o mantenedor em particular pelo [perfil no GitHub](https://github.com/pedrojr). Os relatos são tratados com sigilo.
